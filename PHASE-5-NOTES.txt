Rhino's Roulette Bot v1.5.0
Phase 5 - Persistent viewer database + message section toggles

DATABASE STORAGE
- roulette.db now lives in Electron's Windows AppData/userData folder alongside settings/messages/auth data.
- On the first launch of this version, if AppData does not already contain roulette.db, RouletteBot checks the old project locations:
    data/roulette.db
    roulette.db
  and COPIES the existing database into AppData.
- The old database is intentionally left untouched as a safety backup.
- Once AppData/roulette.db exists, future launches use it and project-folder patches cannot overwrite viewer balances/history.
- Debug -> Open App Data Folder opens the folder containing the live database.

CUSTOM MESSAGE SECTION TOGGLES
- Each Messages sidebar section now has its own master switch:
    General
    Round
    Bets
    Results
    Individual Results
    Compact Results
- Switching a section OFF turns all message types in that section to their simple/plain fallbacks.
- Switching it ON turns all message types in that section back to custom mode.
- Individual message-type switches still work and can create a Mixed section state.
- Message banks are not deleted when a section is turned off.
- Reset All Messages still restores the shipped defaults and turns every custom message type back on.

INSTALL
Extract the patch over the current project root, allow replacements, then run:
    npm start

No new npm dependencies are required.
