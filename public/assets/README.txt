DISCORD ICON

Place the Discord icon used by the OBS overlay here with this exact filename:

    public/assets/discord.png

Recommended:
- PNG with transparent background
- Square image
- 64x64, 128x128, or 256x256 is plenty

The overlay automatically hides the image if this file is missing, so the
credit still reads "Made by Rhino • rhino4w" until the icon is added.

After adding/replacing the icon:
- During development: refresh the OBS Browser Source.
- For a portable release: rebuild the portable ZIP so the icon is included.
